# Getting Started with AgentLedger

One proxy. Full visibility. 40–70% less spend.

## 1. Point your agents at the proxy

```bash
export OPENAI_BASE_URL=agentledger:8787/v1
# Done. Your agents are being tracked.
```

Nothing else changes — same SDKs, same keys, same code.

Open the dashboard and check per-agent, per-team, per-model spend.
"I can finally see where my AI money goes."

answers in microseconds. "I stopped paying for duplicate calls."
